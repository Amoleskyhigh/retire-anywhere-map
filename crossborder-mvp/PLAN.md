# PLAN.md — Retire Anywhere 跨國生活/民情探索 MVP（5國）

## 專案目標
建立第一版網頁，讓使用者可根據：
- 簽證、醫療、稅務、生活成本、社會文化、治安
- 個性特徵（探索/穩健/家庭導向/慢生活）
快速比較已研究國家，並得到可解釋的中性判讀。

## MVP 範圍（第一版）
國家：日本、葡萄牙、西班牙、馬來西亞、泰國

功能：
1. 國家卡片 + 可解釋總分
2. 人格/預算篩選
3. 5國並排比較表
4. 方法論與風險聲明

## 不含（第二版）
- 城市級深度報告
- 自動抓取法規 API
- 使用者帳號/收藏
- AI 個人化問答

## WBS
1) 規格定義（資料欄位、評分權重）
2) 頁面實作（HTML/CSS/JS）
3) QA（功能/按鈕/手機版/console）
4) 部署（GitHub Pages）
5) 回報與每週追蹤提醒

## 風險與備案
- 風險：政策變動快（簽證/稅務）
  - 備案：每個國家加入「更新時間與注意事項」
- 風險：分數被誤認為投資建議
  - 備案：明確免責與中性說明
- 風險：資料不足導致過度簡化
  - 備案：第二版加入來源追溯與信心分數

## DoD（Definition of Done）
- 有可公開訪問連結
- 5國資料完整顯示
- 篩選可用、比較表可讀
- QA_REPORT 明確 `FINAL: 100% PASS`
