# PLAN.md — Retire Anywhere 跨國生活/民情探索 v2.2

## 專案目標
建立 v2.2 網頁，讓使用者可根據：
- 簽證、醫療、稅務、生活成本、社會文化、治安
- 個性特徵（探索/穩健/家庭導向/慢生活）
快速比較已研究國家，並得到可解釋的中性判讀。

## v2.2 範圍
國家：日本、葡萄牙、西班牙、馬來西亞、泰國、越南、希臘、義大利、智利、澳洲（共 10 國）

功能：
1. 中／英文切換與 TWD／USD 幣別切換
2. 3 題問卷與人格／家庭／預算條件
3. Top 3 推薦卡片與其餘國家展開
4. 10 國比較表與其餘列展開
5. 國家詳細 modal、重設流程
6. 方法論與風險聲明

## 後續版本不含項目
- 城市級深度報告（另行開發）
- 自動抓取法規 API
- 使用者帳號/收藏
- AI 個人化問答

## WBS
1) 規格定義（資料欄位、評分權重）
2) 頁面實作（HTML/CSS/JS）
3) QA（功能/按鈕/手機版/console）
4) 部署（GitHub Pages）
5) 回報與每週追蹤提醒

## 風險與備案
- 風險：政策變動快（簽證/稅務）
  - 備案：每個國家加入「更新時間與注意事項」
- 風險：分數被誤認為投資建議
  - 備案：明確免責與中性說明
- 風險：資料不足導致過度簡化
  - 備案：第二版加入來源追溯與信心分數
